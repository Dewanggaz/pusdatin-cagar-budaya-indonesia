# Pusdatin Budaya Nusantara

Portal edukasi budaya Indonesia (React + Vite) yang menampilkan data pakaian adat,
bahasa daerah, rumah adat, seni lukis, dan alat musik tradisional dari berbagai provinsi.


## Struktur proyek

- `src/data/budaya.js` — data budaya per provinsi & kategori (mudah ditambah/diedit).
- `src/components/Navbar.jsx` — navbar dengan animasi indikator geser saat hover + dropdown kategori.
- `src/components/Sidebar.jsx` — sidebar navigasi kategori & provinsi.
- `src/components/BackButton.jsx` — tombol kembali (menggunakan riwayat browser).
- `src/pages/` — semua halaman (Beranda, Provinsi, Kategori, Tentang, 404).
